# Hostel Washing Machine Log

Node.js + Express + Postgres. Google login (college email only), floor-wise start/stop logging, admin dashboard.

## Run locally
1. `npm install`
2. Copy `.env.example` to `.env` and fill in the values
3. `npm start`  ->  http://localhost:3000

## Deploy
See the setup steps in the chat reply: Neon (database) + Google OAuth client + Render (hosting).
Start command: `npm start`   Build command: `npm install`
